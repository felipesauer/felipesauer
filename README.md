# Felipe Sauer · Full Stack Developer

**Open to Full Stack opportunities.** Let's talk on [LinkedIn](https://www.linkedin.com/in/felipe-sauer/).

## `$ whoami`

Hi! I'm a **Full Stack Developer** who ships **libraries with zero production dependencies** and **identical APIs across PHP and TypeScript**. I work end to end: data modeling, API, interface and whatever else it takes to keep a system running in production without surprises.

I like turning tedious, repetitive problems into tools other people can use. Strict typing, automated tests and max-level static analysis are not extras here, they are the default.

**I write code by hand and use AI when it speeds things up.** The tool changes, the judgment does not: architecture, modeling and review are still engineering work.

That balance became a project: [mnema](https://github.com/felipesauer/mnema) keeps a signed record of the decisions behind AI agent work.
